# 视频九宫格预览生成器

一个不打开视频播放窗口的桌面工具：批量选择视频或文件夹（含子文件夹），分别设置 JPG 网格图和 GIF 动图的抽帧数量，按需独立生成。

面向普通用户的安装、设置与操作步骤见[使用说明](使用说明.md)。

## 使用方法

在项目目录执行：

```powershell
npm install
npm start
```

## 打包 Windows 安装版

执行：

```powershell
npm run dist:win
```

生成目录为 `release\win-unpacked`，运行其中的 `视频九宫格预览生成器.exe` 即可。请保留整个 `win-unpacked` 文件夹，因为 FFmpeg 和 Electron 运行文件都在旁边的资源目录中。

生成 Windows 安装包：

```powershell
npm run dist:win:installer
```

安装包在 `release` 目录中。默认按当前用户安装，可更改安装位置；安装后从开始菜单或桌面快捷方式打开。安装版和文件夹版均不在每次启动时解压整个程序。

点击“批量选择视频”，可以一次选择多个视频，也可以分多次追加选择。“选择文件夹（含子文件夹）”会递归找出其中的视频；也可以把视频或文件夹拖进窗口，或拖到 EXE 图标上。分别点击“生成 JPG 预览图”或“生成 GIF 动图”，只会生成所选格式。文件会生成在原视频所在目录：

```text
原视频名预览.jpg
原视频名预览.gif
```

例如 `旅行片段.mp4` 会生成 `旅行片段预览.jpg`。同名预览图会被更新。

JPG 设置中的“影片数据”默认关闭，开启后可选择文件名、大小、分辨率、FPS、时长、视频/音频编码、字幕及注释，并将字段名称切换为中文或英文；文字字体、字号、颜色和数据栏位置也可调整。文件夹字段会把本地路径写入图片，分享前请检查。“其他效果”可为每格加白边、生成灰度矩阵、添加彩色外框和倒角效果。这些选项只作用于 JPG，不改变 GIF；设置会自动保存，也适用于右键菜单及快捷指令生成的 JPG。

支持 MP4、MKV、AVI、MOV、WMV、FLV、WebM、TS、M4V、MPEG、MPG，兼容 MTS、M2TS。实际能否抽帧还取决于内置 FFmpeg 能否解码该文件的视频流。

“每个文件夹最多处理的视频数”默认为 100，可设置 1–10000。每个选中的文件夹单独计数：递归扫描该文件夹及子文件夹，按完整路径的自然顺序取前 N 个；子文件夹与其所属的已选文件夹共用额度。例如选中 5 个文件夹、上限设为 10，最多会从每个文件夹各取 10 个视频。单独选中的视频文件不受该上限限制；多个输入重复命中的视频只处理一次。不人为划分批次。界面按所选视频/文件夹展示，最多显示前 100 项。

“临时图片存储位置”可选择已有文件夹，或恢复到系统临时目录。抽取的帧会在该位置为每个视频建立独立临时文件夹，处理完成后自动清理；JPG/GIF 成品仍保存在原视频所在目录。右键菜单和快速指令也使用界面保存的临时目录设置。请确保该位置有足够的可用空间和写入权限。

勾选“低优先级模式”后，FFmpeg 使用 Windows 低进程优先级、1 个主要处理线程、每次最多 2 路同时解码输入和 1 个补帧任务；未勾选时沿用常规处理策略。每个视频开始前还会检查系统负荷：CPU 忙于 80% 以上，或可用内存低于总量的 15%（最多按 2 GB 计算）时，最多等约 10 秒再继续，避免任务一直卡住。正在运行的 FFmpeg 不会被强行挂起。该设置会保存，且在主界面切换时也会更新小窗任务的低优先级初始值；若随后在小窗里切换，小窗管理的后续后台任务以小窗保存值为准。输出帧数和画质不变，但处理可能明显变慢。它不是硬性的 CPU/内存占用上限，多个独立的右键任务仍可能同时运行。

界面中可以设置 JPG 抽取帧数（1–36）。9 帧会生成标准 3×3 九宫格，其他数量会自动按接近正方形的行列排版。

GIF 有两种抽帧方式：

- “指定帧数”从全片均匀抽取 1–1000 帧，默认 9 帧。“最长播放时长”可设置为 0.1–1000 秒，默认 20 秒。帧数较少时保持每秒 1 帧；超过时长上限时自动加快。GIF 的计时精度是 0.01 秒，程序优先保留所选帧数；如果时长短到无法容纳这些帧，会自动延长。例如 1000 帧设为最长 5 秒时，实际约 10 秒。
- “按每秒帧数抽取”覆盖整个视频，抽帧速率默认 1 帧/秒，可设置为 1–60 帧/秒；不受上述 1000 帧上限和最长播放时长限制。GIF 播放速度独立设置，默认 5 帧/秒，可设置为 0.1–100 帧/秒。例如 20 秒视频设为每秒抽 2 帧，会抽取约 40 帧，以 5 帧/秒播放约 8 秒。长视频或高抽帧速率会生成大量临时帧，耗时与占用空间会增加。

GIF“生成模式”默认为“画质优先”，保持原有 480×270、128 色的编码方式。“体积优先”采用 272×153、最多 48 色，并减少抖动；帧数和播放时长不变。相较上一版的 240×135、32 色，画质有所提升，文件也会变大；具体增幅取决于视频内容，不能保证都在 50% 以内。选择会自动保存，右键菜单和快捷指令也使用保存的模式。

界面结果会显示实际帧数和预计播放时长。

界面分为“文件与进度”和“设置”两页。“文件与进度”页并排显示文件列表和处理进度，高度随窗口大小变化；视频较多时，两处列表各自在区域内滚动。“处理进度”可切换到“处理日志”。设置页左侧为 JPG 设置，右侧依次为 GIF 和其他设置；窗口较窄时改为上下排列。

界面中保存的抽帧方式、帧数、GIF 最长时长、抽帧速率、播放速度、最大处理数、临时图片目录和低优先级模式会用于对应的右键菜单命令。快速指令可用参数临时覆盖数值设置。

右键菜单或快捷指令启动时，默认显示共享的进度小窗；多个后台任务共用一个小窗。主界面已打开时不弹出小窗，仍在主界面显示后台进度。可在“其他设置”中分别关闭右键/指令的小窗、调整完成后是否自动关闭，以及小窗右上角 × 的行为。小窗可独立终止每个视频或文件夹，也可终止全部任务；终止会停止当前 FFmpeg，保留其他已经完成的 JPG/GIF。小窗里的低优先级与自动关闭开关会立即保存；切换小窗低优先级不会改变主界面设置，只对之后启动且由小窗管理的后台进程生效。首次点击 × 会询问“结束任务”或“隐藏至后台”，可勾选记住选择，之后可在设置页改回“每次询问”。隐藏不会最小化到任务栏；点击系统托盘图标可重新打开小窗。

“处理日志”每秒自动刷新当天最近 100 行。无论从视频还是文件夹启动，都会按选取顺序为每个视频记录一条成功、失败或终止；并行时，后一个视频即使先完成，也会等前一个视频完成后再写入，以保持顺序。界面中的失败行标红，磁盘上的 `.log` 仍为普通文本。全部视频处理完毕后才记录成功、失败数量的总体汇总，不记录处理百分比。扫描信息仍会记录；旧版留下的进度行也会从界面中隐藏，不改写历史日志文件。右键菜单或快速指令启动的后台进程也写入同一份日志；打开软件后可在“处理进度”区域看到这些进程正在处理的视频和实时进度。百分比按抽帧、拼图、GIF 编码阶段估算，并非精确的剩余时间。“打开日志位置”可定位当天的 `.log` 文件；“清空当天日志”会先确认，只清空今天的记录，历史日期保留。正在处理的任务会继续写入后续日志。

## 快速指令

如果不需要打开界面，可以直接传入一个或多个视频或文件夹路径。命令会在后台生成预览图，完成后自动结束进程：

JPG 设置和 GIF 设置中的“快捷指令（PowerShell）”始终只显示示例路径，不展示本机程序或已选视频的实际路径。点击复制时会先保存界面设置；如果已选择视频或文件夹，复制出的命令会带入它们的实际路径，可直接粘贴到 PowerShell 执行。未选择时，复制出的命令仍需替换视频或文件夹示例路径。命令会在后台运行，完成后自动退出，无需提前打开软件。

```powershell
npm run quick -- "D:\视频\片段 01.mp4" "D:\视频\片段 02.mov"
```

快速指令默认只生成 JPG。使用 `--gif` 则只生成 GIF，`--frames` 设置抽帧数量，`--gif-duration` 设置 GIF 最长播放时长（秒）：

```powershell
npm run quick -- --gif --frames 120 --gif-duration 15 "D:\视频\片段 01.mp4"
```

打包后的 EXE 也可直接使用：`视频九宫格预览生成器.exe --quick --gif --frames 120 --gif-duration 15 "D:\视频\片段 01.mp4"`。使用 `--jpg` 可明确选择 JPG。快速模式不显示窗口，完成后自动退出。

按每秒帧数抽取的快速指令（此例每秒抽 2 帧、每秒播放 5 帧）：

```powershell
npm run quick -- --gif-every-second --gif-extract-fps 2 --gif-fps 5 "D:\视频\片段 01.mp4"
```

每个选中的文件夹分别最多选取排序后的前 10 个视频：

```powershell
npm run quick -- --max-videos 10 "D:\视频A" "D:\视频B"
```

安装依赖后，也可以使用项目内的 `quick-preview.cmd`。把视频文件拖到这个 `.cmd` 文件上，或在命令行中执行：

```powershell
.\quick-preview.cmd "D:\视频\片段 01.mp4"
```

## Windows 右键菜单

在程序界面点击“设置右键菜单”，即可将“生成 JPG 预览图”和“生成 GIF 动图”分别添加到当前用户的 Windows 资源管理器视频和文件夹右键菜单。右键文件夹时会递归处理其中的视频，遵守界面保存的最大处理数量（默认 100）；生成的文件仍放在各视频所在目录。GIF 右键命令使用界面中保存的抽帧方式和播放设置。点击任一命令后会直接走快速模式，只生成所选格式，完成后自动退出。安装新版后请重新点击一次“设置右键菜单”，以更新命令中的来源标记并使右键小窗设置生效；卸载前请先点击“移除右键菜单”。

如需恢复，点击“移除右键菜单”即可同时清理文件夹和视频菜单。支持 MP4、MKV、AVI、MOV、WMV、FLV、WebM、TS、M4V、MPEG、MPG、MTS 和 M2TS。Windows 11 默认会把传统注册表右键命令放在“显示更多选项”中；这是系统对传统静态右键命令的显示方式。

## 技术说明

- Electron：桌面界面与文件选择。
- ffmpeg-static：随应用提供 FFmpeg，不要求系统单独安装 FFmpeg。
- FFmpeg：快速定位抽帧，并合成 JPG 九宫格与 GIF 动图。

视频只在后台读取和解码，不会自动打开播放器或显示视频内容。

Windows 版会在依赖安装阶段把内置 FFmpeg 切换为无控制台窗口模式，生成图片和 GIF 时不会弹出或闪现命令行窗口。

## 大文件性能

指定帧数模式使用输入级快速跳转：先读取视频时长，再由 FFmpeg 分批跳到每段中点，只解码目标位置附近的少量画面。若少数视频容器的索引不准确，仅对缺失帧启动最多 2 个回退任务进行精确解码。按每秒帧数抽取模式需要顺序扫描完整视频；生成 GIF 时以两次顺序读取临时帧完成调色板与动图编码，避免长视频一次缓存所有帧。

常规模式按半数可用逻辑核心设定 FFmpeg 线程预算，并将 FFmpeg 进程设为较低优先级；低优先级模式进一步收紧线程和同时解码输入，并在系统繁忙时延后启动下一个视频。最大并行处理数量默认 5（可设 1–32），同一任务内可并行，所有主界面、右键菜单和快捷指令任务通过共享名额合计受此上限约束；下调设置后，已有视频会先继续处理，新视频等待空位。Windows 调度器、视频解码器、磁盘和其他程序的负载会变化，因此**不能保证 CPU、内存、磁盘等每项硬件资源都严格不超过 50%**。
